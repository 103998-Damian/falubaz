# Blender – pliki projektu Falubaz

Folder zawiera pliki Blender nieśledzone przez git (wykluczone przez `.gitignore` ze względu na rozmiar).

## Zawartość

| Plik | Opis |
|------|------|
| `fis_speedway_motorcycle.glb` / `.zip` | Model motocykla żużlowego FIS |
| `falubaz_projekt.blend` / `.blend1` | Projekt toru żużlowego z motocyklem |
| `falubaz_projekt.glb` | Eksport projektu toru do formatu GLB (używany w Godot) |

## Uwagi

Pliki `.blend`, `.blend1` i `.glb` są wykluczone z repozytorium — należy je przechowywać lokalnie lub udostępniać przez zewnętrzne storage (np. OneDrive, Google Drive).
